# Immersion Tracker - privacy policy

Publishes the privacy policy for the Language Immersion Tracker Chrome
extension:

https://immersiontracker.github.io/Immersion-tracker-site/privacy

That URL is referenced by the extension's Chrome Web Store listing, so this
repository must stay public and the page must stay reachable.

The extension source lives in a separate private repository. A copy of it was
pushed here by mistake and has been removed; earlier commits in this repo's
history still contain it.
